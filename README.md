### 👩‍💻 About Me

I'm a DevOps / Cloud Infrastructure Engineer with hands-on experience running production and development workloads on **AWS EKS**. My day-to-day work spans Kubernetes, CI/CD automation, networking, and infrastructure-as-code — from scaling voice-AI platforms to fixing broken deployment pipelines.

- 🔭 Currently managing production and dev **EKS clusters**, including Karpenter autoscaling, HPA tuning, and node rightsizing
- ⚙️ Working with **GitHub Actions**, **Terraform**, and **Ansible** to automate infrastructure and deployments
- 🌱 Sharpening my skills in IAM/IRSA, observability (CloudWatch/Prometheus), and infrastructure cost optimization
- 🐍 On the side, I write Python learning notes and enjoy the occasional creative/themed project
